# Glucocalc — Glucose/HbA1c Calculator (iOS)

## Project Overview

A SwiftUI Glucocalc calculator app: estimates HbA1c and average
blood glucose using the 2008 ADAG formulas, plus glucose/HbA1c unit conversions.
Runs on iPhone and iPad. UI is a compact calculator-style card with a numeric
keypad (digits 0-9, `.`, `⌫`, `C`, `=`; bottom row has two empty cells, `.`,
`=`); `=` computes, `C` clears, `⌫` backspaces, with a segmented mode picker
and UK (IFCC) toggle above it. The display is three label/value rows (input +
both outputs) with labels left and values right-aligned in one shared column;
all three values show 0 initially and after `C` (units live in the labels).
System theme
(light/dark adaptive); Help button in the toolbar, presented as a medium/large
detent sheet. The window opens small (420x620) and is freely resizable on iPad
(`defaultSize` + `windowResizability` in `GlucocalcApp.swift`). All unit
conversions are handled by the US/UK toggle (no standalone converter).

**Bundle ID:** `com.jocala.glucocalc`
**Min Target:** iOS 17.0 | **Xcode:** 26.6 | **UI:** SwiftUI

## Math (2008 ADAG formulas)

ADAG formulas, `Calculator.swift`:

- **Calculate eAG** (input HbA1c): `eAG = 28.7 * A1c - 46.7` mg/dl; mmol/L = /18.
  If UK(IFCC) checked, input is mmol/mol: `A1c = 0.09148 * input + 2.152` first.
- **Calculate HbA1c** (input eAG): `A1c = (eAG + 46.7) / 28.7` (%); IFCC `= 10.93*A1c - 23.50`.
  If UK(IFCC) checked, input is mmol/L: `* 18` first.
- **Unit conversions** (mg/dl ↔ mmol/L, % ↔ mmol/mol): handled on the fly by
  the US/UK toggle (see below); the standalone convert dialog was removed as
  redundant. Conversion math: mg/dl→mmol/L `/18`, mmol/L→mg/dl `*18`,
  %→mmol/mol `*10.93 - 23.5`, mmol/mol→% `*0.09148 + 2.152`.
- Input must be `> 0`; otherwise "Invalid input!" alert.
- Result strings always show both units (mg/dl + mmol/L, or % + mmol/mol),
  regardless of the UK(IFCC) checkbox.
- The UK(IFCC) toggle converts the current input to the other unit system on the
  fly (mg/dl ↔ mmol/L in a1c mode, % ↔ mmol/mol in eAG mode) and recomputes the
  results, so input and output stay consistent when switching US/UK.

## Build & Install

### Prerequisites
- macOS with Xcode 26.6 installed
- Apple ID for device deployment (team `9Q77WK7W3R`)
- Physical devices: `appletv`, `jpad`, `jphone`, `mpad`, `opad`

### Device build + install (default: jphone)

```bash
./build.sh            # build + install + launch on jphone
./build.sh opad       # or specify a device
```

Standard `-scheme` builds (`build.sh`). Note: if scheme builds ever fail with
"iOS 26.5 is not installed" / "Supported platforms for the buildables in the
current scheme is empty", the iOS/tvOS simulator runtimes are missing — reinstall
with `xcodebuild -downloadPlatform iOS` (and `tvOS`). `-target` builds bypass
destination resolution and are a working fallback.

Manual simulator build (no runtime installed on this machine currently):

```bash
xcodegen generate
xcodebuild -project Glucocalc.xcodeproj -target Glucocalc -sdk iphonesimulator -configuration Debug build
# product: build/Debug-iphonesimulator/Glucocalc.app
```
